Quick start with an example: handball player

These screenshots document a V3.1.0 demonstration. Values belong to this example, not general cutting settings. License details and personal file paths have been cropped out. Screenshots show the German interface.

1. Load the image

Open Image & project and load the motif with Load image. The original appears on the left; the contour preview is initially empty. Use the back button to return to the main menu.

2. Create the mask

Open Mask & size, set motif width and output mode, then create the mask. This cutting example shows red outer and green inner contours. The status initially reported three separate black components. The exact mask settings were not recorded during the demonstration.

3. Add bridges locally

Open Bridges. Zoom into disconnected parts and add manual connections as needed. The ball and both sleeves were edited in this demonstration. Yellow marks show bridges; those at the ball were labelled 2.0 mm. Follow the status instructions while drawing; double-clicking the destination finishes a connection.

4. Check connections

Review the entire motif, especially narrow connections. This example then reported one black component and 13 bridges. These counts are example results; also inspect the geometry visually. Undo and Redo allow corrections.

5. Smooth and compare

Open Smooth / simplify paths. Stronger smoothing was enabled, maximum deviation was 1.0 mm and strength was 15 / 50, giving an effective limit of 0.300 mm. Click Smooth / update paths and wait for completion. The highlighted field then displayed ≈ 0.299 mm. The preview reported 15,190 → 3,450 nodes (−77.3%), 2,070 curves and 23/23 smoothed contours; the second pass removed another 4,273 nodes. Original contour shows the cyan dashed comparison. The measurement applies to the preview; other motifs and export resolutions can give different values.

6. Save DXF

Open Check & export. This example used High (up to 3000 px) with Include original contour in DXF enabled. Choose Save DXF, select a filename and wait for export validation. The DXF saved status confirms completion. The cyan reference is on REFERENZ_ORIGINAL. Explicitly disable cutting for this layer in your laser software: color alone does not guarantee it will be ignored.

Start quickly

Image & project: load an image or an existing project. The two prompt generators can help prepare a motif first.
Mask & size: select output mode, contours and physical width. Set threshold and inversion, then Create mask.
Bridges: connect islands and add manual connections as needed. Finish the mask and bridges first.
Smooth / simplify paths: set tolerance and strength, then Smooth / update paths. Inspect the result, measured deviation and original comparison.
Check & export: choose export quality, Check result and save SVG or DXF. PNG only saves the current raster mask.
Image & project: also save a .lkfproj file for later editing.

Seven main groups · V3.1.0 navigation

Selecting a group replaces the main menu with its submenu. “← Main menu” returns to the overview. Settings and results are retained. The image and contour preview remain visible. Scroll the right panel to reach lower controls.

  1. Image & project

    Create cut or engraving motifs, load an image, load and save projects.

  2. Mask & size

    Set output mode, cut contours, threshold, inversion, pre-mask smoothing, small-part removal, width and main area; then create the mask.

  3. Bridges

    Set bridge width, automatic width limits and maximum connection length; connect islands, add or delete manual bridges.

  4. Smooth / simplify paths

    Apply protected or stronger Bezier simplification, set deviation and strength, compare the original and reset simplification.

  5. Check & export

    Select export quality, check the result and save optimized PNG, SVG or DXF.

  6. Generate NC file

    Placeholder with no commands. This version does not generate NC files.

  7. Help & settings

    Open help, select language, activate a license, view program information or support the project.

Undo, Redo and Original state remain available across menus. These and the back buttons have borders and a yellow hover effect. Main menu cards become lighter on hover. Main-window tooltips appear after two seconds over a control and disappear when leaving or clicking. Hover does not enable a disabled command.

Recommended order: Image & project → Mask & size (set width first) → Bridges → Smooth / simplify paths → Check & export. Help is accessible through the main menu.

2. Program interface

Where to find the command: Image & project

Loaded image

Shows the source artwork retained for high-resolution exports.

SVG preview

Shows cutting order, ignored contours, and bridges. Manual bridges are edited here. Use the mouse wheel to zoom the preview around the current pointer position. Press F to fit all contours back into the preview window.

Tool panel

Contains modes, mask controls, bridges, smoothing, size, and export.

Status line

Reports components, bridges, warnings, and processing progress.

“Create cut motif” and “Create engraving motif”

Both motif commands first open a local prompt generator. Set subject, material, dimensions and detail, then generate the prompt. Copy prompt copies the text; Open ChatGPT also copies it and opens the matching assistant in the browser. Only this optional step needs internet access and possibly a login. Save the resulting image and use Load image to open it; it is not returned automatically.

3. Output modes

Where to find the command: Mask & size

Cut motif

Black areas become closed vector contours for stencils, signs, decorations, and cut-outs.

Engraving + outer cut

The image remains an embedded raster engraving. Only the largest connected outer area becomes the red cutting contour.

Laser power, speed, focus, and passes are configured in your laser software. KonturFix creates geometry, not machine settings.

4. Optimising the mask

Where to find the command: Mask & size

SettingEffect and recommendation
Black thresholdControls which brightness values are black. Raise it when areas are missing; lower it when shadows merge.
Invert imageSwaps black and white.
Smooth before maskReduces pixel noise. Keep it low to preserve eyes, hair, and lettering.
Remove small partsDeletes isolated areas below a pixel count. Increase only until unwanted specks disappear.

Long calculations run in the background and can be cancelled without accepting a partial result.

Physical width and Main area are under Mask & size. Width in mm determines output size and the scale for bridges and tolerances. Main area selects the largest area or the area near the image centre as the connection reference. Set dimensions before placing bridges.

After changing threshold or inversion, press Create mask. Smooth before mask and Remove small parts rebuild the mask automatically after a short pause. Rebuilding the mask removes existing bridges. Finish mask settings before editing bridges; use Undo for an unwanted change. Long calculations show progress and can be cancelled.

6. Automatic and manual bridges

Where to find the command: Bridges

Bridges retain islands such as pupils, letter centres, or parts of a nose.

Automatic

Connect islands searches for short, collision-free connections, can add two bridges to large islands, and respects width and length limits. Automatic width adapts each bridge between the configured minimum and maximum.

Manual and free bridges

  1. Select Place manual bridge.
  2. Click the first connection point on a black contour. It snaps to the nearest contour point.
  3. Add as many free intermediate points as needed to guide the bridge around eyes, lettering, or fine inner details.
  4. Double-click the target contour to finish the free bridge. Only the start and end points must touch black material.
  5. The yellow live preview shows the path while placing it, using the configured bridge width.
  6. Backspace removes the last point. Right-click or Escape cancels the operation.

The manual width follows Bridge width (mm). After finishing, the bridge is merged into the mask and can later be removed with Delete bridge.

Automatic width applies to Connect islands; minimum and maximum constrain its calculated widths. Manual bridges use Bridge width (mm). Maximum bridge length 0 means unlimited. End manual exits drawing mode. To delete, choose Delete bridge and click the desired yellow connection. Recheck smoothing after bridge edits.

7. Path simplification, smoothing and detail

Where to find the command: Smooth / simplify paths

Legacy SVG smoothing has been removed. Without active simplification, the mask outline is retained; exactly collinear intermediate points may be removed. Pre-mask smoothing is a separate image/mask operation, not Bezier fitting.

After creating the mask, open Smooth / simplify paths. Set maximum deviation and strength, then select Smooth / update paths. The calculated preview and node statistics show the result. Large motifs can take longer.

Protected mode allows a maximum setting of 0.1 mm. Stronger smoothing – like Inkscape allows up to 2 mm and can change the shape more. Effective tolerance = maximum deviation × strength / 50. Example: 1 mm × 15 / 50 = 0.3 mm. Strength 0 retains the original outline.

Stronger mode automatically runs a targeted second pass. Both passes are checked against the original using the same total tolerance; deviations do not accumulate. Two-sided distance and topology checks protect geometry. Critical details and narrow bridges may remain unchanged or stepped. Identical Inkscape output is not guaranteed.

In cutting mode, selected cut paths are processed. For engraving, the function requires BOTH Engraving + outer cut AND Cut outer contour only, and only changes the outer cut contour. Raster engraving and grayscale remain unchanged.

Original outline shows the reference in dashed cyan. Reset simplification restores the original and does not enable legacy smoothing. Undo/Redo manage editing steps. Recheck after changing mask, size or export quality.

DXF reference and measured deviation

Where to find the command: Check & export

Under Check & export, Include original contour in DXF is optional and off by default. Selected original cut contours are added in cyan on REFERENZ_ORIGINAL with the non-plot flag. Explicitly exclude this layer from laser output: no color or DXF flag guarantees that laser software ignores it.

After smoothing, Max. contour deviation · preview displays the largest two-sided shortest distance to the original in mm. It is a numerical approximation with less than 0.001 mm error, not a uniquely defined normal distance at corners. Different export resolutions may produce different contours and distances.

8. Undo and redo

Up to 20 states store masks, bridges, repairs, modes, and relevant parameters. Undo moves back, Redo restores a reverted step, and Original state returns to the first state of the current image or project. Session history is not stored in project files.

9. Saving and opening projects

Where to find the command: Image & project

A .lkfproj file stores the original and work image, base and optimised masks, automatic and manual bridges, and contour, smoothing, size, and export settings. Damaged or incompatible projects are rejected.

Privacy: Licence keys and trial data are never stored in projects.

10. Export formats and quality

Where to find the command: Check & export

FormatUse
PNGOptimised black-and-white mask for inspection.
SVGVector file: green inner contours first, red outer contours last; engraving mode embeds the raster image.
DXFDXF contains cut contours in millimetres: closed polylines or SPLINE entities for simplified Bezier paths. Raster engraving is not included as a DXF image. Check SPLINE support in the receiving program.

Fast uses preview resolution, High recalculates up to 3000 pixels, and Original uses the full source resolution. Filters, bridges, and smoothing scale with output resolution.

Export quality controls SVG and DXF recalculation, not PNG. Save optimized PNG writes the current black-and-white mask without Bezier paths or the optional DXF reference. SVG and DXF are checked before writing; high or original resolution can change processing time and geometry compared with the preview. Contour colors and file order do not replace checking cut order in the laser software. The interface has no SVG stroke-width control.
Check result is directly available under Check & export and requires a calculated mask. Validation also runs before export. Smoothing repairs now adjust the strength of the new path simplification.

11. Export validation and repair

Where to find the command: Check & export

Yellow warnings may be confirmed after inspection; red errors block likely bad cuts. KonturFix checks missing contours, disconnected areas, unsafe or narrow bridges, tiny geometry, self-intersections, and excessive complexity. The repair dialog explains the cause and can start the recommended correction.

Generate NC file

Generate NC file is a separate placeholder menu with no commands. V3.1.0 does not create NC files or control a machine.

Help & settings

Open help or choose German, English, French, Spanish or Italian here. License / activation opens code entry. About shows version and author; Support project opens the support dialog. The top-right license panel provides installation ID, license request and activation. New menus and some functions currently use English labels outside the German interface. Help follows the selected language.

12. Trial and offline licence

Where to find the command: Help & settings

The program can be tested for 30 days. Afterwards the licence panel remains accessible. Enter name and email, create a request containing the installation ID, and paste the received code. Activation is fully offline and uses an Ed25519 signature. The app contains only the public verification key.

A licence is tied to the displayed installation ID.

13. Recommended workflow for faces

  1. Use a high-contrast image with a quiet background.
  2. Adjust threshold until eyes, nose, and mouth remain distinct.
  3. Use small-part removal carefully.
  4. Connect islands automatically, then inspect every bridge.
  5. Delete visually poor bridges and place them manually on unobtrusive shadow edges.
  6. If needed, apply protected path simplification with a small effective tolerance and compare details against the original outline.
  7. Save the project and run export validation.
The mathematically shortest bridge is not always the visually best bridge.

14. Troubleshooting

ProblemSolution
Image is empty or solid blackToggle inversion and move the threshold in the opposite direction.
Important details disappearReduce small-part removal and smoothing.
An island remains looseRaise the bridge length limit, set it to 0, or place a manual bridge.
Original export is slowUse High quality, which limits the long edge to 3000 pixels.
Project will not openUse an unchanged .lkfproj file from a compatible version.

For jagged contours, use Smooth / simplify paths, wait for calculation and compare against the original. Critical corners and narrow bridges may remain. If smoothing is unavailable for engraving, select both Engraving + outer cut and Cut outer contour only. A dash in the deviation field means no valid preview value is available; an ellipsis indicates calculation. The cyan preview comparison and the DXF reference export are independent switches.

15. Shortcuts and final check

Ctrl+Z Undo · Ctrl+Y or Ctrl+Shift+Z Redo · Mouse wheel in the SVG preview: zoom around the pointer · F in the SVG preview: fit all contours to the window

  • Check physical width and material size.
  • Green inner contours must be cut before red outer contours.
  • Every required island needs sufficiently wide bridges.
  • No red validation errors may remain.
  • Verify material, focus, power, and speed in the laser software.

Mouse wheel over preview: zoom around the pointer. F over preview: fit all contours. While drawing a manual bridge: Backspace removes the last point; Escape or right-click cancels; double-click the destination to finish.
